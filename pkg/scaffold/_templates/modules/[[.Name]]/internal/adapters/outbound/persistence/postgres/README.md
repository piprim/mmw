# Postgres adapter

`Postgres[[.Entity | pascal]]Repository` implements `ports.[[.Entity | pascal]]Repository` on
`[[.Name]].[[.Entity]]` through boa; the outbox dispatcher in
`../../events` writes `[[.Name]].event` the same way. Both run on the
executor of the unit of work, so a command's row change and its events share
one transaction.

- `dao/boamodel`: generated by `mise run boa:generate` (bungen, `-t '[[.Name]].event,[[.Name]].[[.Entity]]'`).
  The shipped files are what bungen emits for the two tables of the first
  migrations; regenerate after every migration that changes a table.
- `dao/sqlc`: generated by `mise run sqlc:generate` from `query.sql`, after
  `mise run db:schema:dump` has written `dao/schema.sql`.
- `[[.Entity]]_row.go`: model ↔ snapshot mapping, column list. Never type a
  column name as a string literal in a repository.

Integration tests (`//go:build integration`) start a Testcontainers Postgres
and apply the module migrations: `mise run test:integration`.
