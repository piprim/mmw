# [[.Name | pascal]] module

Generated by `mmw new module`. One bounded context built as a hexagon, with
[[- if .Database]]
one slice: the `[[.Entity]]` aggregate (`Get[[.Entity | pascal]]`, `Delete[[.Entity | pascal]]`).
[[- else]]
one gateway slice: `Send[[.Entity | pascal]]` validates a label and hands it to an
external provider over HTTP, then publishes `[[.Entity | pascal]]SentEvent`.
[[- end]]
[[- if not .Grpc]]
The module is in-proc only: no HTTP listener, no binary; `cmd/cpro` wires it
and other modules call it through `contracts/go/application/[[.Name]]`,
obtained from `Module.Service()`.
[[- end]]
The skill `.claude/skills/hexago-ddd` at the repository root is the reference
for adding slices.

## Layout

| Path | Role |
| --- | --- |
| `[[.Name]].go` | Composition root: `New(ctx, Infrastructure{…})`, [[if .Database]]`Migrate`, [[end]]`Start` |
| `internal/domain/[[.Entity]]/` | [[if .Database]]Aggregate, `Label` value object, `Deleted` event, sentinel errors[[else]]Message, `Label` value object, `Sent` event, sentinel errors[[end]] |
| `internal/application/` | `[[.Entity | pascal]]Service`, [[if .Database]]one query, one transactional command[[else]]one command[[end]] |
| `internal/adapters/inbound/` | [[if .Grpc]]Connect handler, [[end]]proto mapper, in-process contract adapter |
| `internal/adapters/outbound/` | [[if .Database]]boa repository, outbox dispatcher, generated `dao/`[[else]]HTTP gateway, bus publisher[[end]] |
| `internal/infra/` | [[if .Database]]Config, goose migrations (`[[.Name]].event`, `[[.Name]].[[.Entity]]`)[[else]]Config[[end]] |
| `internal/testhelpers/` | In-memory fakes used by every test below the adapters |

## Database

```bash
mise run db:migrate:up      # applies the migrations to DB_URL
mise run db:schema:dump     # writes dao/schema.sql for sqlc
mise run boa:generate       # regenerates dao/boamodel after a migration (bungen on PATH)
mise run sqlc:generate      # regenerates dao/sqlc from query.sql
```
