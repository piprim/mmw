# [[.Name | pascal]] module

Generated by `mmw new module`. One bounded context built as a hexagon, made
of slices: each entity owns its domain package, service, adapters and proto,
and `mmw new entity` adds the next one.
[[- if not .Grpc]]
The module is in-proc only: no HTTP listener, no binary; `cmd/cpro` wires it
and other modules call it through `contracts/go/application/[[.Name]]`,
obtained from `Module.<Entity>Service()`.
[[- end]]
The skill `.claude/skills/hexago-ddd` at the repository root is the reference
for adding slices.

## Layout

| Path | Role |
| --- | --- |
| `[[.Name]].go` | Composition root: `New(ctx, Infrastructure{…})`, [[if .Database]]`Migrate`, [[end]]`Start` |
| `<entity>_wiring.go` | One per slice: builds its service, exposes `<Entity>Service()` |
| `internal/domain/<entity>/` | One package per slice: entity, `Label` value object, events, sentinel errors |
| `internal/application/` | One `<Entity>Service` per slice, its queries and commands |
| `internal/adapters/inbound/` | [[if .Grpc]]Connect handlers, [[end]]proto mappers, in-process contract adapters |
| `internal/adapters/outbound/` | [[if .Database]]boa repositories, outbox dispatcher, generated `dao/`, [[end]]HTTP gateways, bus publisher |
| `internal/infra/` | [[if .Database]]Config, goose migrations (`[[.Name]].event` and one table per slice)[[else]]Config[[end]] |
| `internal/testhelpers/` | In-memory fakes used by every test below the adapters |

## Verify

```bash
mise run arch:check   # layering, must stay at 100 %
mise run lint
mise run test:unit
mise run test:contract
[[- if .Database]]
mise run test:integration   # needs Docker
[[- end]]
```

[[- if .Database]]

## Database

```bash
mise run db:migrate:up      # applies the migrations to DB_URL
mise run db:schema:dump     # writes dao/schema.sql for sqlc
mise run boa:generate       # regenerates dao/boamodel after a migration (repository's tools/bungen)
mise run sqlc:generate      # regenerates dao/sqlc from query.sql
```
[[- end]]

## Next slice

`// mmw:slice-*` markers of `[[.Name]].go`, `events/topics.go`,
`events/proto.go` and `mapper/errors.go`. To grow a slice by hand, follow
`references/slice-recipe.md` of the skill.
